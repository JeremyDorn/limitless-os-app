# Limitless OS für den Mac

Die Desktop-App zum Limitless OS von Jeremy Dorn. Sie zeigt dasselbe wie
[hmos.jeremydorn.de](https://hmos.jeremydorn.de) und erkennt zusätzlich, wann
du vom Rechner weg warst, auch wenn das Fenster zu ist.

Herunterladen: unter [Releases](https://github.com/JeremyDorn/limitless-os-app/releases/latest)
oder direkt im Limitless OS über das Download-Symbol oben rechts.

- Mac mit Apple-Chip (M1 bis M4): `Limitless-OS-mac-apple.dmg`
- Mac mit Intel-Chip: `Limitless-OS-mac-intel.dmg`

Nach der Installation aktualisiert sich die App von selbst.
